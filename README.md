# ECE 495 – Labs

Course lab repository for ECE 495.

## Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/Kdemian/Lab-495-.git
   cd Lab-495-
   ```

2. **Create a branch for your work**
   ```bash
   git checkout -b lab1-your-name
   ```

3. **Navigate to the lab folder you are working on**
   ```bash
   cd Lab1
   ```

4. **Commit and push your changes**
   ```bash
   git add .
   git commit -m "Lab 1: brief description of changes"
   git push origin lab1-your-name
   ```

## Repository Structure

```
Lab-495-/
├── Lab1/          # Lab 1 materials and code
├── Lab2/          # Lab 2 materials and code
├── Lab3/          # Lab 3 materials and code
├── Lab4/          # Lab 4 materials and code
└── README.md      # This file
```

## Lab Submission Guidelines

- Place all source files inside the corresponding `LabN/` folder.
- Include a `README.md` inside each lab folder describing your approach and results.
- Do **not** commit compiled binaries or generated output files (see `.gitignore`).
- Open a Pull Request when your lab is ready for review.
